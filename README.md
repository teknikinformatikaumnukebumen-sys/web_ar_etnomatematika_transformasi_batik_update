# web_ar_etnomatematika_transformasi_batik_update
AR Etnomatematika: Transformasi Geometri Motif Batik Media pembelajaran interaktif untuk siswa SMA. Siswa mengeksplorasi translasi, refleksi, rotasi, dan dilatasi melalui satu motif batik orisinal, lalu memvisualisasikannya dalam mode Augmented Reality berbasis kamera.
